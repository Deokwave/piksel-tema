# piksel-tema

GitHub sayfalarımızdaki piksel arayüzün (kutular, başlıklar, butonlar, rozetler) CSS hali. Köşeler `clip-path` ile piksel piksel kesiliyor, kenarlıklar `box-shadow` ile çiziliyor; resim kullanılmıyor. İlerleme çubuğu için `.pk-ilerleme` sınıfını kullanıp doluluğu `--deger` değişkeniyle (0-100) veriyorsun. `ornek.html` dosyasını açınca hepsini bir arada görebilirsin.
