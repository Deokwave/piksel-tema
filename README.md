# piksel-tema

GitHub sayfalarımızdaki piksel arayüzün (kutular, başlıklar, butonlar, rozetler) CSS hali. Köşeler `clip-path` ile piksel piksel kesiliyor, kenarlıklar `box-shadow` ile çiziliyor; resim kullanılmıyor. `ornek.html` dosyasını açınca hepsini bir arada görebilirsin.
